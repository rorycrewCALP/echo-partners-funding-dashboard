About the data
  • Source: DG ECHO's IATI publication (reporting org XI-IATI-EC_ECHO) via d-portal.org: every grant whose ID sits under one of the last three HIP years. HIP budgets: latest amounts on DG ECHO's HIP pages.
  • Refreshed automatically on the 3rd of each month by a GitHub Action. ECHO publishes commitments at signature only, no disbursements, and its feed lags by months, so the latest year is always incomplete.
  • Coverage varies a lot by HIP: some show almost the whole budget, others under half. Missing money is most likely larger UN and programmatic-partnership grants, but the data doesn't say.
  • Partners are ECHO's direct partners; sub-grantees and local partners are not published. Some partner names are redacted by ECHO. Affiliates are grouped by name matching, so check unusual cases.
  • Sector tags are ECHO's own (vocabulary 98). ECHO doesn't split a grant's value between its tags, so in the sector hover chart a grant with several tags counts in full under each: values by tag don't add up to the partner's total.
  • Country names are shortened where the formal name is long (e.g. DR Congo); country filters also accept ISO codes. Prepared for CALP Network.
